# School-Management-System

web-based **School Management System** designed to help administrators, teachers, and parents manage students, classes, attendance, exams, and performance efficiently.

## Features
- Student registration & profile management
- Class, subject, and timetable management
- Attendance tracking & automated reports
- Exam & grade management
- Teacher & staff management
- Parent notifications & performance dashboards
- Role-based access (Admin, Teacher, Parent)

## Tech Stack
- **Frontend:** React.js + Tailwind CSS
- **Backend:** Python + Django Rest Framework (DRF)
- **Database:** PostgreSQL
- **Authentication:** JWT / OAuth2
- **Deployment:** Render.com / Heroku / AWS
